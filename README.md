# Cartão Saúde Santa Casa — Landing Page

Landing page de captura de leads para o Cartão Saúde Santa Casa, programa de fidelidade e desconto em saúde ligado ao Hospital Santa Casa de Montes Claros e à Clínica Vida Saúde.

## O que tem na página

- Apresentação da marca, benefícios, planos (Individual e Familiar) e rede credenciada.
- Formulário de captura de leads que monta a mensagem automaticamente e abre o WhatsApp.
- Site estático, sem backend e sem build — um único arquivo `index.html`.

## Contato

Todos os botões de WhatsApp da página apontam para Roberto Arlen, responsável pelo Cartão Saúde Santa Casa.

## Deploy

Site estático publicado no Netlify. Não há comando de build; o diretório publicado é a raiz do repositório (`.`).
